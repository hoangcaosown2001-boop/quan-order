# quan-order

App trên điện thoại để **order theo khách** (không theo bàn) và **tra công thức pha chế bằng ảnh** cho quán.
PWA tĩnh (HTML/CSS/JS thuần), chạy offline, dữ liệu chỉ lưu trên máy.

- Mở app: https://hoangcaosown2001-boop.github.io/quan-order/
- Hướng dẫn: [HUONG_DAN.md](HUONG_DAN.md)
- Test: `node --test` (logic) · `node tests/e2e.mjs` (giao diện, Playwright)
